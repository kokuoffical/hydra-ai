# 🐍 Hydra AI — Hacker Dashboard

Hydra AI is a cyber-style GitHub intelligence tool that analyzes user profiles using web scraping and provides a terminal-style interactive interface.

---

## 🚀 Features

- 🔐 User Authentication (Login/Register with SQLite)
- 🕷️ GitHub Data Extraction (No API dependency)
- 🖥️ Hacker-style Terminal UI
- 📂 Repository Scanner
- 🔢 Select Repository by Number
- 📥 Download GitHub Repositories (ZIP)
- ⚡ Fast and Lightweight Web App

---

## 🛠️ Tech Stack

- Python (Flask)
- BeautifulSoup (Web Scraping)
- SQLite (Database)
- HTML, CSS, JavaScript

---

pip install -r requirements.txt
